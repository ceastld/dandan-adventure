# 弹弹奇旅 · Bounce & Beyond

原创网页弹射对战游戏。打开网页即可玩，支持电脑与手机。

- 三位角色、三把武器、三件装备，全部可用。
- 冒险人机、无风靶场、同屏双人三种玩法。
- 风力弹道、可破坏地形、轨迹辅助、道具与胜负结算。
- 自动保存当前浏览器中的装备与冒险进度。

## 运行

使用 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev:pages
```

```sh
npm run check
npm test
npm run build:pages
```

输出为纯静态 dist，可直接部署 GitHub Pages 或 Vercel。代码来自 Sites React starter，静态入口单独打包，部署不需要服务器、数据库或 API Key。保留原有 starter 的 Vinext 配置供后续扩展。

## 操作

W/S 或 ↑/↓ 调角度，A/D 或 ←/→ 移动，空格按住蓄力、松开发射。也可以点击战场瞄准、拖动角度与力度滑杆、点击发射，适用于触屏。攻击方向自动朝向对手。

每回合 60 体力，移动每步 5 点，道具每次 25 点。强力弹伤害提高 50%，治疗恢复 35 HP，护盾吸收 30 伤害。冰晶命中将对手下回合体力降至 30。清空对手生命获胜，最多 60 回合。

人机获胜奖励 150 星币，失败或平局 50，靶场 30。星币作为冒险记录，不设购买流程。角色、武器、装备自由搭配。双人模式为同屏交替操作，不需要联网。
