# 弹弹奇旅 · Bounce & Beyond

原创网页弹射对战游戏。打开网页即可玩，支持电脑与手机。

- 三位角色、三把武器、三件装备，全部可用。
- 冒险人机、无风靶场、同屏双人三种玩法。
- 风力弹道、可破坏地形、轨迹辅助、道具与胜负结算。
- 自动保存当前浏览器中的装备与冒险进度。

## 运行

使用 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev:pages
```

```sh
npm run check
npm test
npm run build:pages
```

输出为纯静态 dist，可直接部署 GitHub Pages 或 Vercel。代码来自 Sites React starter，静态入口单独打包，部署不需要服务器、数据库或 API Key。保留原有 starter 的 Vinext 配置供后续扩展。

## 操作

↑/↓（或 W/S）连续调整角度，←/→（或 A/D）连续移动并转身。按住空格从 0 蓄力，松开发射，达到 100 自动发射；蓄力期间锁定走位与角度。攻击方向跟随角色朝向，地形坡度会修正实际发射角。

角度盘与力度条保留上一发标记，风向指示保留上一回合记录。冒险与双人模式每回合有 30 秒操作时间，靶场不限时。1 选择强力弹，2 治疗，3 护盾，P 结束回合。触屏使用方向按钮和长按发射按钮；靶场还支持点击战场调角度。冒险默认关闭完整轨迹预测，可手动开启辅助。

游戏按帧处理持续按键，不依赖系统的键盘重复速度。失焦、切换标签页、打开弹窗时会取消蓄力与持续移动。双人模式通过“准备好了”交接控制权。

每回合 60 体力，移动每 12 单位消耗 5 点，道具每次 25 点。强力弹伤害提高 50%，治疗恢复 35 HP，护盾吸收 30 伤害。冰晶命中将对手下回合体力降至 30。清空对手生命获胜，最多 60 回合。

人机获胜奖励 150 星币，失败或平局 50，靶场 30。星币作为冒险记录，不设购买流程。角色、武器、装备自由搭配。双人模式为同屏交替操作，不需要联网。
