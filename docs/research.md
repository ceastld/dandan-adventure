# 玩法调研与实现范围

调研日期：2026-09-05。

## 已核实的参考

- 第七大道《弹弹堂》：回合制、角度盘、力度条、上一发记录、风向风力、血量与怒气等构成“观察—瞄准—发射—复盘”循环。[官方战斗界面](https://ddt.wan.com/article/read/id/359.html)
- 经典键盘控制：左右移动、上下调整角度、长按空格蓄力。[官方基本操作](https://ddt.wan.com/article/read/id/373.html)
- 腾讯《弹弹堂》手游：拉线／蓄力双操作，多武器、宠物、道具组合，挖坑、冰冻、高抛等战术。[腾讯开发者商店介绍](https://apps.apple.com/cn/app/弹弹堂/id1115577916)
- 4399《弹弹星球》：竖屏 2v2 弹射策略、时装与社交养成，单手瞄准、多武器。[官方产品页](https://y.4399.com/detail/324)、[官方 H5 入口](https://www.4399.com/flash/251859.htm)。微信版本具体风力公式与回合规则未完成游戏内核验，未采用同名第三方游戏的星球重力描述。

## 本项目的原创设计

《弹弹奇旅》采用晴空浮岛与 Q 版冒险家主题。角色、武器、装备插画由内置 image_gen 原创生成，未使用上述游戏的品牌、角色、美术或源码。最终提示词见 art-prompts.json。

可玩范围：本地 1v1 人机、静止靶场、同屏双人；三种地形及风力；角度／力度／空格蓄力；轨迹辅助开关；爆炸破坏地形；三种武器与三种装备；强力弹、治疗、护盾；胜负与局数奖励；本浏览器进度存档。

当前不含：联网匹配、账户系统、排行榜、充值交易。星币是战斗奖励展示，全部角色装备默认解锁。地图使用同一原创场景的不同光照配色并拥有独立的碰撞地形和风力范围。
